# 02-简单例子-全路径走读

> **场景**：`pi -p "read config.json"` —— 用户通过 print 模式发送一条提示词，LLM 调用 read 工具读取文件，返回文本结果
> **版本**：0.0.3（commit `853a80d26`）
> **源码基准**：当前 `main` 分支源码
> **阅读说明**：本文只走主成功路径，不展开异常/边界/性能优化

## 1. 场景描述

用户执行：

```bash
pi -p "read config.json and show me the content"
```

期望结果：
1. CLI 解析参数，创建运行时
2. 提示词发送给 LLM
3. LLM 决定调用 `read` 工具，传入 `{ path: "config.json" }`
4. read 工具读取文件内容，返回 `ToolResultMessage`
5. LLM 收到文件内容，生成最终回复
6. stdout 输出最终文本

## 2. 全路径 ASCII 图

```
Step 1: CLI 启动
  cli.ts → main(args)
    │
    │ parseArgs → { print: true, messages: ["read config.json ..."] }
    │ resolveAppMode → "print"
    │
Step 2: 创建运行时
    │
    ├── SessionManager.create(cwd, sessionDir)
    ├── createAgentSessionServices() → ModelRuntime, SettingsManager, ResourceLoader
    ├── createAgentSessionRuntime() → AgentSession + Agent
    │     │
    │   Agent 构造时注入:
    │     streamFn → modelRuntime.streamSimple (闭包,调 pi-ai)
    │     convertToLlm → convertToLlmWithBlockImages (包装 convertToLlm)
    │
Step 3: 进入 Print 模式
    │
    ├── runPrintMode(runtime, { mode: "text", initialMessage })
    │     │
    │   session.subscribe(listener)  ← 订阅事件
    │   session.prompt(initialMessage)
    │
Step 4: AgentSession.prompt(text)
    │
    ├── 验证 model 和 auth
    ├── 构建 user message: { role: "user", content: [{type:"text", text}] }
    ├── emitBeforeAgentStart (扩展钩子)
    └── _runAgentPrompt(messages)
          │
          └── agent.prompt(messages)

Step 5: Agent.prompt() → runAgentLoop()
    │
    ├── emit("agent_start"), emit("turn_start")
    ├── 发射 prompt message 的 message_start/end
    └── runLoop()  ← 核心循环开始

Step 6: 第一轮 — LLM 返回 toolCall
    │
    ├── streamAssistantResponse()
    │     │ convertToLlm(messages) → Message[]
    │     │ streamFn(model, context, options) → 调用 LLM Provider
    │     │ 流式接收:
    │     │   toolcall_start → toolcall_delta → toolcall_end → done
    │     └ 返回 AssistantMessage { content: [{ type:"toolCall", name:"read", arguments:{path:"config.json"} }] }
    │
    ├── 提取 toolCalls
    └── executeToolCalls()
          │
          ├── emit("tool_execution_start")
          ├── prepareToolCall()
          │     │ 找到 read 工具
          │     │ validateToolArguments (TypeBox 校验)
          │     │ beforeToolCall hook (扩展钩子)
          │     └ 返回 { kind: "prepared", tool, args }
          │
          ├── executePreparedToolCall()
          │     │ tool.execute("call_id", { path: "config.json" }, signal, onUpdate)
          │     │   → resolveReadPathAsync("config.json", cwd)
          │     │   → ops.access(absolutePath)  ← 检查可读
          │     │   → ops.readFile(absolutePath) ← 读取文件
          │     │   → truncateHead(text)       ← 截断
          │     └ 返回 { content: [{type:"text", text:fileContent}], details: {truncation} }
          │
          ├── finalizeExecutedToolCall()
          │     │ afterToolCall hook (扩展钩子)
          │     └ 返回 { toolCall, result, isError: false }
          │
          ├── emit("tool_execution_end")
          ├── 创建 ToolResultMessage { role: "toolResult", toolCallId, content }
          ├── emit("message_start"), emit("message_end") for toolResult
          └── push to context

Step 7: 第二轮 — LLM 返回最终文本
    │
    ├── runLoop 继续循环
    ├── streamAssistantResponse()
    │     │ context.messages 现在包含: user + assistant(toolCall) + toolResult
    │     │ streamFn(model, context, options) → LLM 看到文件内容
    │     │ 流式接收: text_start → text_delta → text_end → done
    │     └ 返回 AssistantMessage { content: [{type:"text", text:"Here's the content..."}] }
    │
    ├── 无 toolCalls → hasMoreToolCalls = false
    ├── emit("turn_end")
    ├── 无 steering/followUp → 退出内循环
    └── 无 followUp → 退出外循环

Step 8: 输出结果
    │
    ├── emit("agent_end", messages)
    │
    ├── runPrintMode 中:
    │     state.messages[last] → AssistantMessage
    │     提取 content[].text → writeRawStdout(text)
    │
    └── disposeRuntime() → 清理

    ▼
    stdout: "Here's the content of config.json:\n{ ... }"
```

## 4. 脱敏输入/输出

```

```

```json
{
  "systemPrompt": "You are pi, a coding agent... Current working directory: /home/user/project\n",
  "messages": [
    {
      "role": "user",
      "content": [{ "type": "text", "text": "read config.json and show me the content" }],
      "timestamp": 1725086420000
    }
  ],
  "tools": [
    { "name": "read", "description": "Read the contents of a file...", "parameters": { "type": "object", "properties": { "path": { "type": "string" }, "offset": { "type": "number" }, "limit": { "type": "number" } } } },
```

## 5. 事件序列

```
agent_start
  turn_start
    message_start (user)
    message_end   (user)
    message_start (assistant — streaming)
    message_update (toolcall_start)
    message_update (toolcall_delta × N)
    message_update (toolcall_end)
    message_update (done)
    message_end   (assistant)
    tool_execution_start
    tool_execution_end
    message_start (toolResult)
    message_end   (toolResult)
  turn_end
  turn_start
    message_start (assistant — streaming)
    message_update (text_start)
    message_update (text_delta × N)
    message_update (text_end)
    message_update (done)
    message_end   (assistant)
  turn_end
agent_end
```
