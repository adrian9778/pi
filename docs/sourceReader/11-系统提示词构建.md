### 2.2 两条路径

`buildSystemPrompt` 有两条执行路径：**自定义提示词路径**和**默认提示词路径**。

#### 路径 A：自定义提示词（`customPrompt` 有值）

```
customPrompt
  ↓
+ appendSystemPrompt（若有）
  ↓
+ <project_context> 段（若 contextFiles 非空）
  ↓
+ formatSkillsForPrompt(skills)（若 read 工具可用且 skills 非空）
  ↓
+ "Current working directory: {cwd}"
  ↓
返回
```

自定义路径不包含工具列表、行为准则和 pi 文档路径——用户完全掌控提示词内容。

#### 路径 B：默认提示词

```
1. 获取 pi 文档路径: getReadmePath(), getDocsPath(), getExamplesPath()
2. 构建 visibleTools: 过滤出有 toolSnippets 的工具
3. 构建 guidelines（去重）:
   a. 文件浏览准则（根据 bash/powershell/grep/find/ls 组合）
   b. promptGuidelines（用户额外准则）
   c. 固定准则: "Be concise" + "Show file paths clearly"
4. 拼接模板字符串
5. + appendSystemPrompt（若有）
6. + <project_context> 段
7. + formatSkillsForPrompt(skills)（若 read 工具可用且 skills 非空）
8. + "Current working directory: {cwd}"
```
