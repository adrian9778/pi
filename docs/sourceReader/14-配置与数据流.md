### 3.5 增量持久化

```
settings-manager.ts → function persistScopedSettings
偏移：+620
```

**不是全量写入，而是增量合并**：

```typescript
persistScopedSettings(scope, snapshotSettings, modifiedFields, modifiedNestedFields): void {
  storage.withLock(scope, (current) => {
    const currentFileSettings = current ? migrate(JSON.parse(stripBom(current))) : {};
    const merged = { ...currentFileSettings };

    for (const field of modifiedFields) {
      if (modifiedNestedFields.has(field) && typeof value === "object") {
        // 嵌套字段：只更新修改过的子键
        const baseNested = currentFileSettings[field] ?? {};
        for (const nestedKey of modifiedNestedFields.get(field)) {
          baseNested[nestedKey] = snapshotSettings[field][nestedKey];
        }
        merged[field] = baseNested;
      } else {
        // 顶层字段：直接替换
        merged[field] = snapshotSettings[field];
      }
    }
    return JSON.stringify(merged, null, 2);
  });
}
```

**设计目的**：当用户在会话中修改设置时（如切换模型），只写入修改过的字段，不丢失手动编辑的其他字段。

### 3.7 项目信任

```
settings-manager.ts → function setProjectTrusted
偏移：+497
```

```typescript
setProjectTrusted(trusted: boolean): void {
  this.projectTrusted = trusted;
  this.modifiedProjectFields.clear();
  this.modifiedProjectNestedFields.clear();

  if (!trusted) {
    // 不信任：清空项目设置
    this.projectSettings = {};
    this.settings = deepMerge(this.globalSettings, this.projectSettings);
  } else {
    // 信任：从存储重新加载项目设置
    const projectLoad = tryLoadFromStorage(this.storage, "project", true);
    this.projectSettings = projectLoad.settings;
    this.settings = deepMerge(this.globalSettings, this.projectSettings);
  }
}
```

**安全模型**：项目级 `.pi/settings.json` 可能包含恶意扩展路径。在用户明确信任项目之前，不加载项目设置。

## 6. 会话数据流

### 6.1 会话存储

```
默认: {agentDir}/sessions/
自定义: settings.sessionDir 或 --session-dir CLI 参数
```

每个会话是一个 `.jsonl` 文件，文件名 `{uuidv7}-session.jsonl`。

### 6.2 会话生命周期

```
创建: SessionManager.create()
  → 生成 UUIDv7
  → 写入 SessionHeader (type="session", version=3)
  → 首条助手消息触发文件创建 (延迟写入)

追加: appendMessage(entry)
  → parentId = leafId
  → 生成新 id (UUIDv7)
  → _appendEntry: push, set byId, advance leafId, _persist
  → _persist: 首次创建文件 (openSync "wx"), 后续 appendFileSync

分支: branch(fromId)
  → leafId = fromId (只移动指针，不修改历史)
  → 下次 append 创建新分支

继续: continueRecent()
  → 找最新会话文件
  → open() 加载
  → 不追加新 entry，直接使用

Fork: forkFrom(sourcePath, fromId)
  → 加载源会话 entries
  → 新 header (parentSession = sourcePath)
  → 复制 entries
  → 从 fromId 分支
```
