## 源码定位约定

本库使用 **文件路径 + 符号名 + 函数内相对偏移** 定位源码，不依赖绝对行号。

示例：

```
packages/agent/src/agent-loop.ts
函数：runLoop
偏移：+12 ～ +30
```

详见 [00-文档规范与源码定位约定](00-文档规范与源码定位约定.md)。
